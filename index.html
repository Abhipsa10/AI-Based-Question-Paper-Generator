How It Works

A seamless integration of user input and complex AI processing.

1

Configure Parameters

User: Selects subject, total marks, and difficulty ratio.
AI: Loads syllabus embeddings and historical exam data.

2

Semantic Search

User: Specifies Bloom's taxonomy requirements.
AI: Queries the vector database for highly relevant, non-repetitive questions.

3

Algorithm Balancing

User: Reviews the generated draft.
AI: Optimizes marks distribution and shuffles options to prevent pattern biases.

4

Finalize & Export

User: Makes manual tweaks if necessary and clicks export.
AI: Compiles the final document with formatting and creates an answer key.
